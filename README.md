## 🤖 What is Simple Linear Regression?

**Simple Linear Regression** is a supervised Machine Learning algorithm used to predict a continuous numerical value based on one independent variable.

It identifies the linear relationship between two variables:

- **Independent Variable (X):** Years of Experience.
- **Dependent Variable (Y):** Salary.

In this project:

- Input: Years of Experience.
- Output: Predicted Salary.

For example, if a person has 5 years of experience, the trained model predicts their estimated salary based on the relationship learned from the training dataset.

### Mathematical Formula

Simple Linear Regression uses the following equation:

`Y = mX + C`

Where:

- `Y` = Predicted Salary.
- `X` = Years of Experience.
- `m` = Slope (Coefficient).
- `C` = Intercept.

The model calculates the best-fit line by minimizing the difference between actual salary values and predicted salary values.

## 📁 Project Files Explanation

### 1. templates/

This folder contains the HTML templates used by the Flask application.

**index.html**

- Provides the user interface.
- Allows users to enter their years of experience.
- Contains the input form for salary prediction.
- Sends the input value to the Flask backend.

**result.html**

- Displays the predicted salary.
- Shows the result generated by the Machine Learning model.

### 2. app.py

This is the main Python application file.

Responsibilities:

- Imports the required Python libraries.
- Loads the trained Machine Learning model.
- Creates the Flask application.
- Accepts user input from the HTML form.
- Passes the input to the trained model.
- Generates the salary prediction.
- Displays the result on the web page.

### 3. SLR Model File

This file contains the previously trained Simple Linear Regression model.

The model is saved using Pickle so that it can be loaded and used for predictions.

Instead of training the model every time the application starts, the saved model is loaded directly.

### 4. requirements.txt

This file contains all the Python libraries and dependencies required to execute the project.

For example:

```text
Flask
numpy
pandas
scikit-learn
matplotlib
seaborn
gunicorn
```

Install all dependencies using:

```bash
pip install -r requirements.txt
```

### 5. Procfile

The Procfile specifies the command used to start the application on a supported deployment platform.

For a Flask application using Gunicorn, an example command is:

```text
web: gunicorn app:app
```

This assumes that your Flask application instance is named `app` inside `app.py`.
